# 关键词搜索指数与投放洞察服务 (小红书聚光)

## 模块说明
本模块位于独立文件夹 `keyword_service` 中，专门负责小红书聚光关键词指标的抓取、展示、直接生成飞书表格以及定时自动同步任务调度。

## 功能特性
1. **多词空格并行检索**：支持在输入框内输入多个关键词（空格分隔），系统并行调取聚光后台接口 `/api/light/ad/keyword/analysis/distribution`，秒级拉取四大指标：
   - 搜索指数 (`keywordSearchNum`)
   - 广告曝光量 (`keywordAdsImpNum`)
   - 广告笔记数 (`adsNoteNum`)
   - 平均市场出价 (`keywordBid`)
2. **复合表头规范展示**：
   - 第一行：日期区间（每个日期占4列）
   - 第二行：四个字段（搜索指数、广告曝光量、广告笔记数、平均市场出价）
   - 第三行及后续行：按关键词独立分行呈现
3. **直接生成飞书在线表格**：一键调用飞书官方机器人接口，在指定共享文件夹自动创建电子表格、按列分块写入完整数据，并配置公开可编辑。
4. **定时自动同步任务**：支持一键将检索结果转为定时同步任务，配置更新模式（全量覆盖/增量追加）与执行频率（每天12:30等），后台 APScheduler 自动调度。
5. **管理看板板块**：
   - **同步任务列表**：管理任务状态（运行中/暂停/立即执行/删除）
   - **运行记录与状态**：查看每次同步与直接生成的耗时、状态、更新词数与直达飞书表格链接。

## Token 与 Cookie 配置
- Token 文件位置：`keyword_service/token.json`
- 后续如果更新 Cookie，只需覆盖该文件或修改其中 `cookie` 与 `v_seller_id` 字段即可，代码会自动热读取。

## 访问路径
- 网页入口：`http://127.0.0.1:8088/keyword`
