# PROJECT.md - jzt_sync

## 概述
京准通达人营销日明细自动更新至飞书，沿用 jzt_sync.zip 的 52 个任务配置。卓睿计划任务每天北京时间 15:00、周一 09:00 运行；启萃计划任务每天北京时间 13:30、周一 09:00 运行。两个任务分别只同步对应表，单浏览器窗口检查登录、刷新 Cookie 后执行增量同步。

## 目录
- daily.py：定时主入口、互斥锁、退出码、结构化状态日志。
- refresh_login.py / local_login.py：登录检查、自动提交、原业务 Cookie 上下文保留与实际报表验证。
- daily_client.py / daily_sync.py：直连接口、写入限速与限流退避、全表日期扫描、备份与回读。
- run_daily_jzt.ps1 / install_daily_task.ps1：日志包装和 Windows 每日调度。
- configs/：原任务映射；logs/：运行结果；backups/：子表备份；.profiles/：独立登录状态。
- 原始 main.py/client.py/sync_service.py 保留；实际入口详见 README.md。

## 已知边界
- 京东拼图/短信必须人工完成；只自动提交一次，随后在同一窗口等待。
- 单独失效的业务 skpp 会话不能仅靠主账号重新登录恢复；失败会保护原 token 并记录原因，需更新对应业务 Cookie。
- 新增营销任务需要加入 configs 映射；本次仅自动同步原有 52 个任务。
- 原 Cookie 的两个业务账号上下文必须保留。实测纯主账号 Cookie 单独无法下载这两个业务报表，混用会失败。
- 单张表出现重复日期或错误任务归属时停止该任务，其他任务可继续，整次结果标为失败。
